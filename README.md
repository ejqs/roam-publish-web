# roam-publish-web

Publish and share roam pages and blocks.

This repository interacts with [roam-publish](https://github.com/ejqs/roam-publish) and contains the api routes and way to display the pages.

This project will not be "vibe coded" but AI assistance will be used. I'll try to follow [ghostty](https://github.com/ghostty-org/ghostty/blob/main/CONTRIBUTING.md)'s philosophy on AI Usage.

## Dependencies

- [Nextjs](https://nextjs.org) as full-stack framework
- [Drizzle](https://orm.drizzle.team) as ORM (whatever that means)
- [Better-auth](https://better-auth.com) for auth
- [Umami.is](https://umami.is) as privacy focused analytics
- [shadcn/ui](https://ui.shadcn.com) as component library
- [Railway](https://railway.com) as Cloud Provider
