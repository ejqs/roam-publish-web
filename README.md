# roam-publish-server

Publish and share roam pages and blocks.

This repository interacts with [roam-publish](https://github.com/ejqs/roam-publish) and contains the api routes and way to display the pages.

This project will not be "vibe coded" but AI assistance will be used. I follow [ghostty](https://github.com/ghostty-org/ghostty/blob/main/CONTRIBUTING.md)'s philosophy on AI Usage.
